# RoboScan 工程量扫描（v0.2.3）

基于 Robo 精简改造的 iOS LiDAR 房间扫描应用，只保留房间扫描、历史记录和工程量清单导出，不连接任何后端。

## 功能

- RoomPlan LiDAR 房间扫描
- 中文界面
- 自动生成工程量清单（Excel .xlsx，多 Sheet）
- USDZ 模型导出与 3D 预览
- 按个数项目可拍摄实拍照片并嵌入 Excel
- 支持导入 CSV 单价表自动计算合价
- 所有数据仅保存在本机

## 本地编译

```bash
brew install xcodegen
cd ios
xcodegen generate
open RoboScan.xcodeproj
```

在 Xcode 中把 `DEVELOPMENT_TEAM` 改成自己的 Apple 团队，连接带 LiDAR 的 iPhone 后运行。

## 工程量清单

扫描完成后可导出 `工程量清单.xlsx`，包含汇总表、土建装饰、门窗、洁具给排水、家具家电、待点云结构、照片附件等 Sheet：

- 表头包含房间名称、房间类型、建筑面积、层高、房间体积、房间周长、房间形状、楼层等概要
- 水泥砂浆楼地面、找平层、墙面抹灰（扣除门窗洞口）、天棚、踢脚线、顶角线、墙体积、防水面积
- 每樘门、每扇窗的尺寸、洞口面积、洞口周长，以及合计
- 洁具给排水点位、家具家电逐个明细和分类数量
- 每项带计算式、清单编码（参考）和合价
- 梁、板、柱目前为占位，需要后续点云分割计算

单价表 CSV 格式示例：

```csv
清单编码,项目名称,单位,综合单价
011201001,墙面一般抹灰,m²,28.50
010801001,门,樘,680.00
```
